> "Колір — це частота вібрації Смислу."

Цей документ визначає канонічну палітру для візуалізації вимірів (Dimensions) та шарів (Layers) у системі s0fractal.

| Color | Hex | Glyph | Archetype | Meaning |
|-------|-----|-------|-----------|---------|
| **Void** | `#000000` | `~` | **Singularity** | Ніщо. Початок координат. Потенціал. Фон терміналу. |
| **Light**| `#FFFFFF` | `Σ` | **Synthesis** | Все. Спостерігач. Сума всіх спектрів. Проекція чистого знання. |

## 4. UI/CLI Implementation Guide

### Для Prompt (Starship/Zsh):
* **Шлях:** Відображається кольором мови (`~/void/sh` -> Green).
* **Гліф:** Відображається кольором шару (глибини).

### Для IDE (VS Code / Zellij Themes):
* **Активна вкладка:** Колір поточного виміру.
* **Бордери:** Градієнт від Чорного (низ) до Білого (верх).

### Візуалізація Зв'язків:
Якщо `0-ts` (Deep Blue) підключений до `~` (Black), лінія зв'язку має бути градієнтом `#000000` -> `#002266`.
Це створює ефект, що код "виростає" з темряви.
